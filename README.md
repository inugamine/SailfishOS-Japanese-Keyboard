# japanese-kana-kbd
Japanese flick keyboard for Sailfish OS / Sailfish OS 日本語フリックキーボード

Sailfish OS 向けの日本語フリック入力キーボードです。

## 概要

フィンランド発のスマートフォン OS である Sailfish OS でも日本語入力がやりたくて開発しています。

## 機能

- 12キー日本語フリック入力  
- ひらがな・カタカナ切り替え
- 辞書ベースの漢字変換（SKK-JISYO.L を利用）

## 注意事項

### キーボード切り替え機能との干渉

Sailfish OS では複数のキーボードを有効にしていると、横スワイプでキーボード切り替えが発動します。  
これがフリック入力の横方向と干渉するため、**他のキーボード（英語キーボードなど）を無効化**することをおすすめします。

**設定方法:**
1. Setting → Text Input → Keyboards
2. 「日本語(かな)」以外を無効化
